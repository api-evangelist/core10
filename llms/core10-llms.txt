# Core10

> Core10, Inc. was a U.S.-based fintech software development and API integration firm founded
> in 2016 by Lee Farabaugh and Jeff Martin in Franklin, Tennessee, with delivery centers in
> Martin, Tennessee and Huntington, West Virginia, built on a domestic-outsourcing model it
> trademarked as Hereshore(R). It wrote custom software, core-banking integrations and API
> layers for community banks, credit unions and fintechs, acquired Accrue Technologies in 2021
> for digital lending and account opening, and spun its implementation practice out as Monarch
> in January 2024.

## Status

**The Core10 brand is retired.** As of 2026-08-11, `core10.io` 301-redirects to
`monarchfts.com`, where the company operates as **Monarch** — an Intapp DealCloud
implementation, configuration and managed-services consultancy for private capital firms
(private equity, venture capital, private credit, investment banking, family offices, fund of
funds, real estate). The Monarch about page states plainly: "Core10 is now Monarch." The
**Accrue** platform trades independently at `getaccrue.com` under its own leadership.

**There is no public API.** Core10 built API integrations for other companies for nearly a
decade and never published a developer program, public API, SDK or machine-readable contract
of its own — and neither successor brand does today. Probes for `/openapi.json`,
`/openapi.yaml`, `/swagger.json`, `/api-docs`, `/docs`, `/graphql`, `/llms.txt`,
`/.well-known/security.txt`, `/.well-known/api-catalog`, `/.well-known/agent-card.json` and
`/.well-known/agent.json` returned 404 on `monarchfts.com`, `blog.core10.io`, `getaccrue.com`
and `api.getaccrue.com`. No Core10-lineage GitHub organization exists. No first-party package
exists on npm or PyPI.

**Caution for crawlers and agents:** `core10.io` answers **HTTP 200 for every path**, but the
body is byte-identical to the `monarchfts.com` homepage on all of them. It is a catch-all
soft-404. A 200 from that host is not evidence that a document exists.

`api.getaccrue.com` does resolve (AWS ELB, nginx) and is the only live API host in the
lineage, but it returns a bare nginx 404 on every discovery path and nothing public links to
it. The host is real; the contract is not public.
